# Project Brief: Repeater Event Handlers

> Pre-Research Stage — Everything here reflects initial assumptions and early analysis. Nothing has been validated yet.

## Context
This work lives in the Studio 2 Editor, focused on the Repeater component. The trigger is a product spec requirement: before Studio 2 can fully define the Repeater component, the team needs to understand how event handlers currently work in Wix Studio — both in general and specifically when a Repeater is selected — so those learnings can inform what gets exposed in Studio 2.

## Direction
Research the current Wix Studio editor's event handler model, with a focus on Repeater behavior. Use those findings to produce a concrete list of event handlers to expose when a Repeater component is selected in Studio 2.

## Goal
Respond to a request — define the spec for which event handlers the Repeater component should expose in Studio 2.

## Target Group
Developers and Partners (agencies/freelancers) building sites and apps with Studio 2.
